# nender — Мониторинг закупок ЕИС

Локальное приложение для Windows 11, которое автоматически ищет новые закупки на сайте ЕИС (zakupki.gov.ru) по сохранённым поисковым профилям и каждое утро отправляет email-рассылку только по новым результатам.

## Функциональность

- Поиск по ИНН заказчика (несколько компаний)
- Фильтрация по региону и городу
- Поиск по ключевым словам (подстрока, без учёта регистра)
- Несколько сохранённых поисковых профилей
- Ежедневная утренняя проверка по расписанию
- Email-рассылка только по новым закупкам (без повторов)
- Локальная база SQLite
- Журнал событий

## Стек

- Python 3.11+
- PySide6 (интерфейс Windows)
- SQLite (локальная база)
- requests (интеграция с ЕИС)
- schedule (планировщик)
- smtplib (email-рассылка)

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
```

## Настройка сервиса ЕИС

Для работы с официальным сервисом отдачи информации ЕИС необходимо зарегистрироваться как получатель данных на сайте zakupki.gov.ru.
Логин и токен доступа вводятся в настройках приложения (вкладка «Подключение ЕИС»).

## Настройка SMTP

В настройках приложения укажите:
- Хост SMTP-сервера (например smtp.yandex.ru или smtp.mail.ru)
- Порт (465 для SSL, 587 для TLS)
- Логин и пароль от почтового ящика
- Email отправителя
